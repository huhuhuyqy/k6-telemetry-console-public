# Multi-game telemetry × Flydigi K6 Shift Light Demo

这是 K6 Telemetry Console 的浏览器版本。本地桥接服务读取 AMS2、AC EVO、AC、ACC、LMU 和 Forza Horizon 5/6 的遥测，把驾驶状态发送给网页，再通过 WebHID 控制 K6 灯带。页面也保留了手动模拟器用于脱离游戏测试。

## 当前版本

网页版的界面、灯效逻辑和游戏解析器已与 Electron `0.2.8` 同步。Electron 目录是共享运行代码的唯一源；同步的七个文件是 `acevo_bridge.py`、`ams2_bridge.py`、`game_sources.py`、`app.js`、`runtime-core.mjs`、`index.html` 和 `style.css`。网页版继续使用自己的 `start-demo.ps1`，默认端口为 `8765`。

本版本包含 ACC 完整 Graphics 映射、AMS2 比赛状态/车辆标志/温度修正，以及 Forza 232/311/323/324/331 字节报文兼容和轮胎温度单位修正。Electron 专属的全屏后台节流修复位于 `main.js`，浏览器版不包含该文件；浏览器在后台时是否节流由 Chrome/Edge 自身决定。

连接 K6 时会按 A3 的声明长度读取并保存灯光 RAM `0x04` 的完整原始配置；它兼容 A4 封装 `LGHT`、直接 `LGHT` 和固件内置 opaque 预设。关闭页面时会尝试原样写回。普通浏览器不能保证标签页销毁期间异步 WebHID 操作一定完成，因此浏览器版属于尽力恢复；Electron 版会阻止窗口立即销毁并等待恢复事务完成。只有快照为空、全 `00`、全 `FF` 或 A3 分块不完整时才进入保护模式。

## 运行

1. 用 USB 或 2.4G 接收器连接 K6，先退出飞智空间站等可能占用设备的软件。
2. 在 PowerShell 中进入本目录，执行：

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\start-demo.ps1
   ```

3. 在 AMS2 中进入 `Options → System`，把 `Shared Memory` 设置为 `Project CARS 2`，更改后建议重启游戏。
4. 使用 Chrome 或 Edge 打开 `http://localhost:8765/`。
5. 页面数据源保持“AMS2 实时遥测”，状态栏显示“AMS2 实时”后，点击“连接 K6”。
6. 不启动游戏也可以把数据源切换为“手动模拟器”，拖动转速/刹车或使用自动扫转速。

## 灯效规则

- 低转：蓝色
- 巡航：绿色
- 中高转：黄色
- 高转：橙色
- 到达换挡转速：纯红/纯白快速闪烁（每相位 140ms）
- 刹车：纯红/熄灭快速闪烁，优先级最高

界面显示 12 段换挡灯。K6 当前在线工具公开的灯光协议只提供整条灯带统一颜色和内置动画，没有公开逐颗 LED 的实时流式接口，因此硬件侧使用颜色分级模拟换挡提示。

## 协议依据与安全性

实现依据来自飞智在线 K6 配置工具当前公开前端：

- HID：VID `0x37D7`，K6/APEX 6 PID `0x2502`，usage page `0xFFA0`
- 帧头：`5A A5`
- RAM 读/写命令：`0xA3` / `0xA4`
- 灯光 RAM 域：`0x04`（`0x05` 是按键映射配置域）
- 灯光二进制 magic：`LGHT`，版本 `2`

同一 VID/PID 还会暴露 `usagePage 0xFFEE / report 5` 等接口，但它不是配置通道。抓包确认空间站实际通过 `0xFFA0 / report 0 / 32B` 写灯；Demo 因此严格拒绝其他接口。灯光亮度按空间站使用的 `0–100` 范围编码。

Demo 只写运行时 RAM，不调用保存到闪存的命令；重连或配置刷新后通常会恢复原配置。协议并非正式公开 SDK，固件更新可能改变行为，请先在低风险环境测试。

连接时 Demo 会先发送 A4 `ABORT (0x03)`，清理上一次异常退出可能留下的写入事务。分块失败时也会自动清理并重试一次，避免持续高速重试使设备保持忙状态。

如果浏览器底层 `sendReport()` 失败，Demo 会自动关闭并重新打开 HID 设备后重试。仍失败通常意味着飞智空间站、另一个网页标签或后台程序正在占用设备接口；完全退出这些程序并重新插拔接收器后再连接。

针对部分接收器固件返回的 A4 `状态 1`，Demo 会在事务内延迟重试；16 字节分块持续失败时，会清理事务并自动降为 8 字节分块。

## AMS2 遥测桥接

`ams2_bridge.py` 使用 Windows 原生 `OpenFileMappingW` 只读打开 `$pcars2$`，不会在游戏未启动时创建假共享内存。它通过 `http://localhost:8765/api/telemetry` 提供：

- `RPM` / `MaxRPM`
- `Gear`（包括倒挡 `R` 和空挡 `N`）
- `Brake` / `Throttle`
- 车速、车辆名称、游戏和比赛状态

页面以 25Hz 读取遥测。车辆的 `MaxRPM` 变化时，换挡阈值会保持原来的红线百分比自动缩放；例如默认阈值始终约为车辆红线的 90%。游戏关闭或共享内存超过两秒不再更新时，状态栏会显示遥测暂停，不会继续把旧数据当作实时数据。

## Assetto Corsa EVO 0.8

页面数据源新增“Assetto Corsa EVO 0.8 实时遥测”。桥接程序只读游戏已经创建的共享内存，不会创建假的映射：

- `Local\\acevo_pmf_physics`：转速、红线、挡位、油门、刹车、ABS/TC 介入、DRS、ERS、刹车温度、轮胎温度、滑移、损伤和出界轮胎；
- `Local\\acevo_pmf_graphics`：换挡提示、旗帜、进站限速、燃油、电池、油温/水温和四轮胎压/温度。
- `graphics.instrumentation`：雨刷级别、左右转向、双闪/远光闪灯、警告灯、雨灯和大灯状态。

可直接触发 K6 整条灯带的效果包括：换挡、刹车、ABS、TC、DRS、ERS、进站限速、旗帜、逆向、损伤、刹车过热和轮胎偏热。当前 K6 协议仍是整条灯带 RGB 写入，不能把四个车轮或左右两侧映射为独立灯珠。

核心灯效优先级严格为：`ABS > 刹车 > 换挡 > 转速 > TC > 逆向 > DRS`。不再使用“72% 以上才算转速”的折中规则；只要当前有转速背景，它就按用户指定顺序优先于 TC、逆向和 DRS。

普通警告/换挡使用 120 ms 亮 / 120 ms 灭；双闪和转向灯使用较慢的 300 ms 亮 / 300 ms 灭；刹车灯从约 300 ms 亮灭周期随刹车压力连续加快到约 80 ms 亮灭周期。所有时钟都由独立的 20 ms 页面刷新驱动，避免遥测轮询和 HID 分块写入造成节奏漂移。

车辆灯光状态会映射为低亮度背景或短闪：转向/双闪为橙色、雨刷/雨灯为蓝色、大灯为低亮白色、远光闪灯为白色快速闪烁。它们位于核心驾驶提示之后；如果展厅没有发布共享内存更新，页面不会伪造这些状态。

启动游戏后，在页面把数据源切换为 EVO。桥接会区分驾驶、回放和展厅：非驾驶状态不会把静止共享内存误判为 ABS、TC、转速等驾驶警告，展厅仍会转发共享内存实际提供的转向灯、大灯和雨刷等设备状态。如果状态栏停在“等待 AC EVO”，请确认游戏已经创建共享内存，并重启本地桥接服务。EVO 共享内存结构可能随早期访问更新调整，读取异常时页面会显示等待/暂停而不会继续发送旧数据。

## 新增游戏数据源

页面数据源现在还支持：

- **Assetto Corsa**：读取 `Local\\acpmf_physics`、`Local\\acpmf_graphics`、`Local\\acpmf_static`。
- **ACC**：读取同名共享内存，但使用 ACC 的结构布局。
- **Le Mans Ultimate**：读取内置 `LMU_Data` 共享内存；需要进入驾驶界面后才有玩家车辆数据。
- **Forza Horizon 5 / 6**：读取 UDP Data Out。默认监听 `127.0.0.1:5300`，可用环境变量 `FORZA_UDP_PORT` 改端口。

Forza 设置方法：在游戏的 HUD / Gameplay 遥测设置中打开 UDP Race Telemetry，目标 IP 填 `127.0.0.1`，端口填 `5300`，数据格式选择 Sled 或 Dash。FH5/FH6 的 UDP 数据没有统一的转向灯、双闪、雨刷字段，所以这两项不会伪造触发；能读到的刹车、ABS、转速和挡位会直接套用 K6 灯效。

所有数据源共用同一优先级：`ABS > 刹车 > 换挡 > 转速 > TC > 逆向 > DRS`。刹车闪烁周期由踏板压力连续控制，轻踩较慢、重踩更快；AMS2 现在也使用这条与 AC EVO 相同的路径。游戏没有公开某个事件字段时，桥接层返回 `false`，不会用猜测值触发灯效。

AC/ACC 共享内存的挡位会归一化为 `R=-1、N=0、1挡=1`。AMS2 没有已确认的 TC action 字段，因此不会再用未公开的车辆标志位猜测 TC。

启动脚本只会复用服务名、版本和项目根目录都与当前副本一致的 `8765` 服务。端口若被旧版或其他程序占用，它会明确报错，不会打开错误页面。遥测请求也带超时、取消和数据源代次检查，快速切换游戏时旧请求不能覆盖新来源。

## 回归测试与共享文件检查

Electron 目录是规范源。在 Electron 目录执行：

```powershell
pnpm test
pnpm run sync:browser
pnpm run check:browser
```

测试覆盖协议帧长度、A3 截断响应、灯光快照校验、完整 A4 事务串行化、灯效优先级、各游戏结构大小、AC/ACC 挡位以及 Forza 324/331 字节报文。
